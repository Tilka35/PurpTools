
This guide will take you through setting up, configuring and installing a Raspberry Pi 4 Model B out of the box. This Raspberry Pi will be used for monitoring the home (LAN) network, being placed ahead the ISP-provided router to monitor any traffic ingress and egress

## Shopping List
You will need
- Raspberry Pi (this guide is for edition 4 Model B)
- Raspberry Pi (or any USB C) power cable
- SD Card

Recommended but optional
- Monitor
- Keyboard
- Mouse
- HMDI -> Mini HDMI Cable
- SD Card adapter for flashing

## Step 1 - Getting the Raspberry Pi ready for use
The Raspberry Pi 4 Model B kit comes with a pre-flashed SD Card with RaspbianOS on it ready for use.

In case you still need flash the SD card, use the SD Card adapter to insert the SD Card into the adapter and connect it to you device. Use the flashing tool to flash RaspbianOS on the SD Card.
